# DomainChecker - 域名批量查询工具

一款基于 Python Tkinter 开发的桌面应用程序，用于批量查询域名的 DNS 解析状态。

## 功能特性

- **猴子模式** - 自动生成随机域名（1-10位字母数字组合）
- **输入模式** - 手动输入域名主体进行查询
- **批量查询** - 支持 150+ 种域名后缀（com、cn、net、org 等）
- **并发查询** - 多线程并行处理，提高查询效率
- **实时进度** - 进度条实时显示查询进度
- **自定义超时** - 可调节 DNS 解析超时时间（1-10秒）
- **一键访问** - 查询结果支持直接打开浏览器访问

## 使用说明

1. **猴子模式**：点击后自动生成随机域名，点击"开始"批量查询
2. **输入模式**：在输入框输入域名主体（如 `baidu`），点击"开始"查询
3. **开始**：启动域名查询
4. **停止**：中断当前查询任务
5. **清除**：清空查询结果列表
6. **超时设置**：调节 DNS 解析超时时间（默认 3 秒）

## 环境要求

- Python 3.7+
- tkinter（Python 标准库）
- PIL（Pillow，用于窗口图标）

## 安装运行

```bash
# 克隆项目
git clone <repository-url>
cd PythonRweb

# 安装依赖
pip install Pillow

# 运行程序
python Main.py
```

## 打包发布

使用 PyInstaller 打包为 Windows 可执行文件：

```bash
pyinstaller DomainChecker.spec
```

打包完成后，exe 文件位于 `dist/` 目录。

## 技术实现

- **GUI 框架**：Tkinter
- **并发处理**：ThreadPoolExecutor（10个工作线程）
- **域名后缀**：内置 150+ 种常见顶级域名
- **DNS 查询**：socket.gethostbyname
- **进度更新**：线程安全的状态同步
